# arcsnd: sound boards on the MiSTer's ARM, from MAME

One server for the sound boards of more than one core (Konami Hornet, SNK Hyper NeoGeo 64), picked
by `/tmp/CORENAME`. Each file keeps its licence and copyright holders in its header.
